# Playwright module bundle v1

This package lock is the reviewed Node-module source for AX42 Playwright
browser checks. The official pinned Playwright image supplies Chromium and
its operating-system dependencies; this bundle supplies the matching
`playwright` and `playwright-core` Node modules.

Install it through `../install-toolchain-prerequisites.sh`. Do not run
`npm install`, `npx playwright install`, or an unpinned package download from
a WorkSession browser check.
